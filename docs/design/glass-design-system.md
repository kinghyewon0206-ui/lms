# ECONOVA Glass — 디자인 시스템 시안 (2026-11-21)

> Prism 을 대체할 새 시각 방향의 **시안 단계**. 전체 화면 적용은 소유자 검토 뒤에 한다.
> 시안은 로컬 전용 주소에서만 열린다 (`ECONOVA_DESIGN_PROTOTYPES=1`, 운영에서 켜면 앱이 시작 거부).

## 1. 개념 — "시장이 만나는 빛"
- 배경은 서로 교차하는 두 줄기의 부드러운 빛(청록 = 공급, 사프란 = 수요)이다. ECONOVA 로고도 두 곡선이 한 점(균형)에서 만나는 유리 렌즈다.
- 그 위에 젖빛 유리 패널이 층을 이룬다. 유리는 탐색·조작·요약(내비게이션, 카드, 대시보드 위젯, 레슨 주변 도구)에만 쓴다.
- **긴 레슨 본문은 유리가 아니라 거의 불투명한 "종이"(흰색 95%) 위에** 둔다. 오래 읽어도 대비가 유지된다.
- 강조점은 하나다: 첫 화면의 **움직이는 시장 그래프**(소득 슬라이더 → 수요 이동 → 가격·수량·지출 즉시 변화). 나머지는 조용하게.

## 3. 글꼴
- **Bricolage Grotesque** (제목, 가변 광학 크기): 큰 제목은 좁은 자간, 개성 있는 형태.
- **Onest** (본문·UI): 읽기 쉬운 산세리프. 숫자는 tabular-nums.
- Google 버튼만 Google Sans Medium (Google 가이드).
- 크기: 13 / 16 / 18 / 22 / 28 / 38 / 최대 70px. 레슨 본문 17.2px · 행간 1.75 · 최대 68자.

## 4. 재질
- 유리: 흰색 74%→46% 그라데이션 + `backdrop-filter: blur(20px) saturate(165%)` + **빛나는 1px 테두리**(마스크로 그린 그라데이션 테두리, 밝은 모서리) + 넓고 옅은 그림자.
- 강한 유리(88%→68%), 부드러운 유리(blur 12px), **흑요석 유리**(AI 튜터·주 버튼: 어두운 반투명 + 청록 내부광).
- 포인터를 따라가는 반사광(hover 때만, 마우스 기기만).
- 반경 위계: 패널 28 / 카드 22 / 컨트롤 14 / 알약 999.
- 대체: `prefers-reduced-transparency` 또는 backdrop-filter 미지원 → 불투명 흰/남색 면. `prefers-reduced-motion` → 모든 움직임 정지(그래프는 완성된 상태로). 고대비 모드 → 테두리 선.
- 성능: 큰 blur 는 내비·패널에만. 카드 안 색 코어는 backdrop 이 아닌 일반 blur 한 번(정적).

## 5. 구성 요소 (시안 4번 페이지에 상태별로 모아 둠)
- 버튼: 주(흑요석) / 보조(투명 유리) / 조용한 / 어두운 바탕용 — 기본·hover·눌림·키보드 포커스·비활성·로딩·성공·잠김
- Google 버튼(Light 테마 그대로, 유리 아님)
- 입력: 기본·포커스·오류(aria-invalid)·비활성·도움말, 선택 상자
- 세그먼트 컨트롤(난이도·탭): 유리 트랙 위를 미끄러지는 렌즈, 난이도 막대 아이콘
- 퀴즈 선택지: 기본·선택·정답·오답·잠김 (상태 램프)
- 칩·상태 점·진행 막대·상태 메시지(성공·오류·안내)
- 강좌 카드: 강좌 색의 흐린 빛 코어 + 유리 렌즈 + 지나가는 반사 줄 + 큰 번호(강좌 순서)
- 대시보드: 진행 링, 이어서 학습(단계 막대), 진단 레이더, 추천 목록, AI 튜터(흑요석), 실험실 미니 그래프, 주간 막대, SDG 진행, 업적 메달
- 레슨: 떠 있는 내비, 머리 패널(이동 경로·칩·난이도), 왼쪽 목차(읽은 곳 표시·현재 위치), 종이 본문, 오른쪽 진행·퀴즈·튜터

## 7. 확인한 것
- 실제 브라우저(앱 내장 브라우저)에서 1440×900 과 375×812(모바일) 로 네 페이지를 직접 보고 고침: 링크색 상속, 강좌 코어 원판 → 흐린 빛+렌즈, 레이더 라벨 잘림, 주간 막대 높이, 진행 링, 모바일 메뉴 버튼, 섹션 머리 배치, 레슨·구성 요소 페이지 가로 넘침(세그먼트 컨트롤·이전/다음 버튼), 잠긴 퀴즈 버튼 대비.
- 모바일 4페이지 모두 가로 스크롤 없음(문서 폭 = 화면 폭 375).
- 키보드: Tab 순서(본문 건너뛰기 → 내비 → 버튼), 포커스 링 3px `#2F5BFF` 확인. 모바일 메뉴 열기 확인.
- 시장 그래프: 소득 +30% → 가격 $5.20, 수량 78, 지출 $406 (식 Qd = 120(1+i) − 15P, Qs = 15P 와 일치).
- **확인하지 못함:** reduced-motion·reduced-transparency 실제 에뮬레이션(브라우저 도구가 지원하지 않음 — CSS 규칙만 있음), 실제 저사양 휴대폰 GPU 성능, Safari·Firefox, 스크린리더 낭독.

## 8. 전체 적용 전에 바꿀 점 (권장)
1. 레슨 본문 종이의 글자 크기·폭을 실제 학생 1~2명에게 읽혀 보고 확정.
2. 대시보드 위젯은 실제 데이터 모양(수강 0개·진단 전·완주 등 빈 상태)을 먼저 설계.
3. 업적·연속 학습일은 지금 앱에 없는 기능이다 → 넣을지 결정 (넣지 않으면 그 자리를 "다음 할 일"로).
4. 퀴즈·결과·관리 화면 시안 추가 (관리 화면은 유리를 최소화).
5. 글꼴 2종(Bricolage Grotesque, Onest)은 Google Fonts 에서 불러온다 → 필요하면 `public/` 에 직접 넣어 외부 요청을 없앤다.

## 9. 전체 적용 (2026-11-21, 소유자 승인 후)
- 단일 스타일시트 `public/static/style.css` 를 Glass 시스템으로 다시 썼다 (기존 클래스 이름 유지 → 모든 화면이 같은 토큰·부품을 쓴다). 시안 전용 `public/static/glass/glass.css` 는 시안 페이지에만 남는다.
- 공유 부품: `templates/_ui.html` (선 아이콘, ECONOVA 마크, Google 버튼), `econova/ui_charts.py` (진단 레이더 — 실제 결과만).
- 적용 화면: 공통 틀(떠 있는 유리 내비·배경 빛·바닥글), 랜딩(실제 9개 강좌, 시장 그래프), 로그인·가입(Google 버튼은 Google Light 테마), 계정, 대시보드(실제 수강·진도·진단 레이더·추천 — 업적·연속 학습일은 기능이 없어 넣지 않음), 강좌 목록·상세, 레슨(종이 본문, 유리 목차·난이도), 진단·퀴즈·최종 평가·결과(선택지 램프: 기본·hover·선택·정답·오답·비활성·포커스), 실험실, AI 튜터(흑요석), 토론, 리포트, 캡스톤, 관리자(절제된 유리, AI 확인 ≠ 사람 승인 표시 유지), 403·404·405·500.
- 성능: backdrop-filter 는 떠 있거나 고정되는 요소(내비·레슨 목차·평가 진행 막대·캡스톤 저장 막대·대기 화면)에만. 카드의 유리 느낌은 반투명 채움 + 빛 테두리로 낸다(카드마다 blur 없음). 휴대폰에서는 배경 빛 이동 애니메이션을 끈다. 글꼴 2종은 Google Fonts(SIL OFL)에서 display=swap.
- 대체: prefers-reduced-motion(움직임 정지), prefers-reduced-transparency·backdrop-filter 미지원(불투명 면), 고대비 모드(테두리).
- 남은 일: Safari·Firefox 실기 확인, 실제 휴대폰 GPU 성능 확인, 스크린리더 낭독 확인 (이 환경에서는 Chromium 계열 내장 브라우저만 확인).
