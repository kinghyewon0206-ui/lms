# ECONOVA 새 UI 방향 3가지 (선택용, 2026-11-21)

> **선택 전에는 전면 재디자인을 구현하지 않는다.** 재디자인은 모든 기능(진단·레슨 3단계·퀴즈·시뮬레이션·튜터·토론·캡스톤·관리 화면)을 그대로 유지한다.
> 참고 사이트는 모방하지 않고 원리만 빌린다. 로고·일러스트·문구를 복사하지 않는다.
> 스크린샷: Claude in Chrome 으로 2026-11-21 직접 열어 찍은 9장. 저작권 때문에 공개 저장소에 넣지 않고 `~/econova-private/design-refs/` 에만 둔다.
> 열어 보지 않은 사이트는 "코드만 확인" 으로 표시했다.

## A. Broadsheet — "경제 잡지처럼 읽히는 교과서"
- **개념:** 신문·연구 잡지의 편집 디자인. 큰 세리프 제목, 좁은 본문 칼럼, 여백의 주석, 도표에 "Figure 1" 캡션. 신뢰감과 학문적 무게.
- **참고:**
  - [Works in Progress](https://worksinprogress.co) — 스크린샷 A1: 콜라주 일러스트, 노란 강조 띠, 얇은 괘선 내비
  - [Our World in Data](https://ourworldindata.org) — A2: 남색 헤더 + 세리프 제목, 차트 카드 격자, 주제 칩
  - [The Pudding](https://pudding.cool) — A3: 번호 붙은 이야기 카드, 강한 단색 썸네일, 고정폭 메타 정보
  - [Aeon](https://aeon.co) — 코드만 확인
- **색:** 종이 `#F6F1E7`, 잉크 `#1B1A17`, 붉은 강조 `#B3122E`, 청록 `#0E6B5C`, 남색 `#1F3A5F` (SDG 색은 작은 칩으로만)
- **글꼴:** Fraunces(제목), Source Serif 4(본문), Inter(UI), IBM Plex Mono(숫자·데이터)
- **레이아웃:** 12단 그리드, 본문 65자 폭, 오른쪽 여백에 핵심 용어·출처 주석. 카드보다 괘선과 여백으로 구획.
- **움직임:** 최소. 스크롤에 맞춰 그래프 선이 그려지는 정도. `prefers-reduced-motion` 존중.
- **랜딩:** 1면 신문처럼 큰 헤드라인("Economics explains the world's biggest problems") + 오늘의 도표 + 9개 강좌 목차.
- **대시보드:** "내 학습 신문" — 진도를 표로, 추천을 편집자 메모처럼.
- **강좌 카드/레슨:** 호수 번호(No. 01) + SDG 칩 + 한 줄 요약. 레슨은 장(chapter) 형식, 난이도 탭은 판(edition) 전환처럼.
- **강점:** 경제학·연구 이미지와 가장 잘 맞음. 텍스트가 많은 3단계 레슨에 최적. 심사위원에게 "진지한 교육 도구" 인상.
- **약점:** 고등학생에게 딱딱하게 보일 수 있음. 퀴즈·게임 요소의 재미가 약함. 세리프 웹폰트 로딩 비용.

## B. Market Terminal — "살아 있는 경제 데이터 화면"
- **개념:** 금융 앱·인터랙티브 설명서의 어두운 데이터 화면. 숫자가 움직이고, 슬라이더로 가정을 바꾸면 그래프가 즉시 반응.
- **참고:**
  - [Robinhood](https://robinhood.com/us/en/) — B2: 검은 배경 + 라임 강조, 거대한 세리프 헤드라인 위에 움직이는 가격선, 기간 탭(1D·1W…)
  - [Mercury](https://mercury.com) — B1: 차분한 핀테크 톤, 반투명 내비, 큰 사진 위 짧은 문구 (참고: 첫 화면은 어두운 단말기 느낌이 아니라 사진 중심이었다)
  - [Bartosz Ciechanowski](https://ciechanow.ski/bicycle/) — B3: 본문 사이에 슬라이더로 조작하는 시뮬레이션, 색이 있는 용어 강조
  - [Reuters Graphics](https://www.reuters.com/graphics/), [Teenage Engineering](https://teenage.engineering) — 코드만 확인
- **색:** 배경 `#0E1012`, 라임 `#C6F432`(상승·정답), 코랄 `#FF7A59`(하락·오답), 파랑 `#6CB4FF`(정보), 회색 단계 5개
- **글꼴:** Space Grotesk(제목) 또는 Instrument Serif(포인트), Inter(본문), JetBrains Mono(숫자)
- **레이아웃:** 대시보드형 패널 격자. 레슨은 가운데 본문 + 오른쪽 "라이브 도표" 패널.
- **움직임:** 숫자 카운트업, 그래프 전이, 슬라이더 즉시 반응 (150~250ms).
- **랜딩:** 검은 화면에 실시간처럼 움직이는 수요·공급 곡선 + "Move the market" 슬라이더.
- **대시보드:** 진도를 티커·스파크라인으로, 진단 결과를 레이더 차트로.
- **강점:** 시뮬레이션·데이터가 주인공. 시연에서 가장 화려함. 10대에게 "멋있음".
- **약점:** 긴 영어 본문을 어두운 배경에서 읽기 피로. 주식 앱 연상 → 투기 이미지 위험(c07 개인 금융과 충돌 가능). 접근성(대비) 관리가 어려움.

## C. Studio Tactile — "손으로 만지는 경제 놀이터"
- **개념:** 두꺼운 테두리·딱딱한 그림자의 네오브루탈리즘. 버튼이 눌리고 카드가 들썩인다. 밝고 장난스럽지만 정돈됨.
- **참고:**
  - [Gumroad](https://gumroad.com) — C1: 크림 배경, 굵은 산세리프 헤드라인, 분홍 3D 코인, 검은 테두리 카드
  - [Brilliant](https://brilliant.org) — C2: 문제 카드를 부채꼴로 펼친 히어로, 초록 기본 버튼, 손으로 그린 듯한 도표
  - [Duolingo](https://www.duolingo.com) — C3: 캐릭터 일러스트, 큰 둥근 버튼, 단순한 두 갈래 선택
  - [Mailchimp](https://mailchimp.com), [Flourish](https://flourish.studio) — 코드만 확인
- **색:** 크림 `#FFF6E9`, 잉크 `#1A1A1A`, 코발트 `#2B44E0`, 분홍 `#FF8FD8`, 노랑 `#FFD23F`, 민트 `#6FE3B4`
- **글꼴:** Bricolage Grotesque(제목), Figtree 또는 DM Sans(본문), Young Serif(포인트), Space Mono(숫자)
- **레이아웃:** 2px 테두리 + 4px 오프셋 그림자 카드, 큰 둥근 버튼, 스티커형 배지(SDG·난이도).
- **움직임:** 눌림(translate 2px), 정답 시 스티커 튀어나옴, 진도 막대 채우기.
- **랜딩:** 크림 배경에 "Economics you can touch" + 9개 강좌가 스티커 카드로 흩어진 그리드.
- **대시보드:** 학습 연속일·배지·다음 할 일 카드 3장.
- **강점:** 고등학생 친화도 최고. 퀴즈·피드백이 즐거움. 지금 Prism UI 와 가장 가까워 전환 비용이 낮음.
- **약점:** 장난스러워 보여 학술 신뢰도가 떨어질 수 있음. 레퍼런스(Gumroad·Duolingo)와 비슷해 보이지 않게 조심해야 함. 정보 밀도가 낮음.

## 추천
**A(Broadsheet)를 기본으로, B 의 시뮬레이션·대시보드 패널과 C 의 촉감 있는 퀴즈 버튼을 일부 가져오는 혼합안.**
- 이유: ECONOVA 의 핵심은 길고 정확한 3단계 레슨과 출처다. A 가 그것을 가장 잘 읽히게 한다.
- 심사(학술 대회)에서 신뢰감이 중요하다.
- 시뮬레이션 화면만 B 의 "라이브 도표" 감각을 쓰면 시연의 볼거리도 확보된다.
- 위험: 10대에게 딱딱할 수 있음 → 퀴즈·진도에만 C 의 눌림 버튼과 색 배지를 쓴다.

## 선택 뒤 진행 방식
1. 선택한 방향으로 랜딩·대시보드·레슨 3개 화면 시안(실제 템플릿) → 소유자 확인
2. 디자인 토큰 교체(`static/style.css` 변수) → 나머지 화면
3. 기존 테스트 전체 + 화면별 확인 (기능 변화 없음)
