## 2. 레슨 학습자료
| 레슨 | 학습목표 (요약) | 하 / 중 / 상 차이 |
|---|---|---|
| L1 | 시장 실패·외부효과 구분 · 사적/외부/사회적 비용·편익 계산 · 과잉·과소 생산을 그래프와 식으로 | 하: 공장 연기·예방접종 이야기 / 중: 사회적 비용 곡선이 공급곡선 위에 있는 이유 / 상: 사회적 비용 곡선 Qs = c + d(P − md), 과잉 생산량 b·d·md/(b + d) |
| L2 | 배제성·경합성으로 재화 구분 · 무임승차와 공공재 과소 공급 · 공유지의 비극과 해결책 | 하: 가로등·바다 물고기 / 중: 두 기준 분류, 정부 공급과 해결책 비교 / 상: 사회적 한계 편익의 세로 합(MSB = ΣMB), 죄수의 딜레마, 평균 vs 한계 어획량 |
| L3 | 직접 규제·오염세·배출권·재산권 비교 · 탄소세의 가격·거래량·세수·배출·귀착 계산 · 외부 피해를 넣은 후생 평가와 SDG 논의 | 하: 오염에 값 매기기 / 중: S → S+t 그래프, 부담 비율 / 상: Pc·Pp 공식, W(t) = k·t·(md − t/2) 미분 → 피구세 t = md |

## 3. 탄소세 시뮬레이션 연결 (기존 기능만 사용)
- **어디에:** 강좌 JSON 에 이미 있던 대로 L3 에만 `simulations: ["carbon-tax"]`. 레슨 페이지 순서상 개념 → 난이도별 설명 → 예제 → 그래프 →
  실제 사례 → SDG 사례 **다음에** 시뮬레이션이 나온다 (개념을 먼저 설명하고 시뮬레이션을 쓴다).
- **수치 일관성:** L3 예제 1~3 과 그래프는 위젯이 처음 보여 주는 기본값(a 100, b 2, c 10, d 1, t 6, md 6, e 1)의 결과와 같다
  (소비자 가격 32, 생산자 가격 26, 거래량 36, 세수 216, 시장 내부 손실 12, 피한 피해 24, 사회적 후생 변화 +12, 배출량 40 → 36).
  저작 스크립트가 `econova/simulations.py` 의 `carbon_tax()` 를 직접 불러 확인했고, `tests/test_c03_content.py` 가 이를 고정한다
  (시뮬레이터 공식이나 기본값이 바뀌면 테스트가 실패한다).
- **변수 ↔ 학습목표:** t·소비자/생산자 가격·세수·배출량 → 목표 2 (효과와 귀착), b·d 변경 → 부담 비율, md·사회적 후생 변화 → 목표 3 (피구세).
- **시뮬레이션 뒤 질문 (레슨 본문에 있음):** 하 — t 를 0 부터 올리며 가격·거래량·배출량 관찰 / 중 — 결과표를 예제와 비교, b 를 바꿔 소비자 부담 비율 변화 /
  상 — t = 3, 6, 12 의 후생 변화를 W(t) 식과 비교, md 를 바꾸면 최적 t 가 어디로 옮겨 가는지. SDG 토론 질문도 시뮬레이션의 세수·소비자 부담을 근거로 쓰게 한다.
- **레슨이 언급하는 결과표 항목 이름**(예: '소비자가 내는 가격', '사회적 후생 변화 (가정)')은 실제 시뮬레이터 결과표 이름과 같아야 한다는 테스트를 두었다.
  레슨은 시뮬레이터에 없는 기능(사회적 비용 곡선 그리기, 배출권 거래 모드 등)을 안내하지 않는다.
- **시뮬레이터 코드는 고치지 않았다.** 아래 6장에 필요해 보이는 앱 변경을 따로 적었다.

## 6. 앱 변경이 필요할 수 있는 것 (이번에 하지 않음, 따로 결정)
1. **시뮬레이션 안내 글 자리:** 레슨 JSON 에는 시뮬레이션 구역에 넣을 안내·질문 필드가 없다. 지금은 난이도별 본문 마지막 소절에 안내를 넣었다.
   `simulation_guide` 같은 필드를 스키마에 더하면 위젯 바로 옆에 보여 줄 수 있다.
2. **사회적 비용 곡선:** 위젯 그래프는 D, S, S+t 만 그린다. md 를 넣어도 사회적 비용 곡선(S + md)은 그리지 않는다. 피구세 설명에는 이 선이 있으면 좋다.
3. **처음 값 지정:** 레슨마다 위젯 처음 값을 다르게 줄 수 없다 (항상 시뮬레이터 기본값). 그래서 L3 예제를 기본값에 맞췄다.
4. **배출권 거래 모드·외부 편익(보조금) 모드는 없다.** L1·L2 에는 시뮬레이션을 붙이지 않았다.
