## 1. c03 탄소세 시뮬레이션 단위
- **문제:** 실험 처음 값(단위당 세금 t = $6, 단위당 배출 e = 1 kg)은 배출 1톤당 약 $6,000 에 해당한다. 현실의 탄소 가격 수준(톤당 수십 달러 단위)과
  크게 달라 학생이 숫자를 현실 수치로 오해할 수 있다. 레슨·위젯은 md·e 가 "가정값"이라고 밝히고 있다.
- **제안 (택 1, 사람 결정):**
  - A. 앱 변경 없이 레슨 문구 보강: "이 모형의 단위·크기는 설명용이며 실제 탄소 가격과 비교하면 안 된다"는 문장을 L3 하·중·상과 SDG 사례에 명시. (콘텐츠 버전만 올림)
  - B. 시뮬레이터 배출 단위를 "tonnes per unit" 으로 바꾸고 처음 값 e 를 0.1 t 정도로 조정 → 톤당 가격이 $60 수준. 레슨 예제 1~3 과 시뮬레이터 처음 값을 함께 바꾸고
    `tests/test_c03_content.py` 의 고정값도 갱신. (앱 변경 + 콘텐츠 변경, 별도 승인)
  - 권장: 지금은 A, 시뮬레이터 개선 작업(축 이름 설정 등)과 묶어 B 검토.

## 2. c04 출처가 직접 뒷받침하지 않는 설명
- 해당: 70의 법칙, 퍼센트포인트, 제3 요인·역인과, 상대/절대 탈동조화, 생산함수 형태, 현금 보유 회피, 물가 안정 과정의 일시적 고용 둔화.
- **제안:** (a) 사람이 표준 교과 지식으로 인정하면 그대로 두고 검토 문서에 "교과 일반 지식" 으로 표시, (b) 아니면 실제로 여는 출처
  (예: OpenStax 해당 절의 다른 페이지, 통계 교과서의 상관·인과 절)를 찾아 연결. 출처를 지어내지 않는다.

## 3. c05 최저임금·수요독점
- 독립 AI 검토 뒤 연구 결과 서술을 "양쪽 연구 모두 논쟁 중"으로 균형 맞춤. 수요독점에서 최저임금이 고용을 늘릴 수 있다는 부분은 OpenStax 14.2 가
  직접 분석하지 않는 **표준 이론 확장(AI 설명)** 이다.
- **제안:** 사람 검토 때 (a) 이론 설명으로 유지하되 "이론상 가능하며 현실에서 얼마나 흔한지는 논쟁 중" 표현 확인, (b) 열리는 학술·공공 출처를 찾으면 연결.
  특정 정책 결론을 정답으로 묻는 문항은 두지 않는다 (현재도 없음).

## 4. 수치형 문항 허용 오차
- 현황 (c01~c05 수치형 43문항): 정수 답 26개는 허용 오차 0, 정수 답 10개는 0.01, 정수 답 1개는 1.0, 소수 답은 0.01~0.11 로 제각각이다.
  소수 답 문항은 모두 반올림 자리 안내가 있다.
- **제안 정책 (승인 전까지 적용하지 않음):**
  1. 정답이 정확한 정수인 문항: 허용 오차 0 (지문에 반올림 안내가 없을 때).
  2. 반올림을 요구하는 문항: 허용 오차 = 요구 자리의 절반 (소수 첫째 자리 → 0.05, 둘째 자리 → 0.005) + 아주 작은 여유.
  3. 어떤 경우에도 흔한 오답 방법(예: 단리/복리 혼동, 근사식)의 결과는 허용 범위 밖이어야 한다 → 문항마다 오답 방법 값을 계산해 확인.
  4. 화폐는 "nearest cent" 를 기본 안내로 쓴다.
- 적용하면 바뀌는 문항은 문항 version 이 오르고 정답 키가 다시 만들어진다 (학생 기록이 없는 초안 단계라 지금 적용 비용이 가장 낮다).
