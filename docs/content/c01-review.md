## 2. 레슨 학습자료
| 레슨 | 학습목표 (요약) | 하 / 중 / 상 차이 |
|---|---|---|
| L1 | 희소성과 선택 · 경제의 기본 문제와 경제 체제(전통·명령·시장·혼합) · 분업과 특화 | 하: 용돈으로 고르기 / 중: 세 가지 기본 문제와 체제 비교, 분업 생산량 계산 / 상: 동아리 예산의 교환 비율(공 1개 = 간식 2.5세트) |
| L2 | 기회비용 계산 · 매몰비용과 한계적 사고 · 생산 가능 곡선과 기회비용 체증 | 하: 아르바이트 vs 영화 / 중: 예산 제약의 상대가격 / 상: 추가 편익·비용 비교표, 생산 가능 곡선 구간별 기회비용 |
| L3 | 소비 선택과 자원·쓰레기 · 사적 비용과 사회적 비용 · 정보·가격·보증금·재사용 정책 비교 | 하: 급식 잔반 계산 / 중: 다회용 컵 손익분기 / 상: 외부 비용과 부담금 설계 |

- 모든 수치는 "가상의 예" 로 표시했고 실제 통계를 지어내지 않았다. 풀이 예제 계산은 로더가 다시 계산해 확인한다
  (차이·곱·비율 검사). 상급 생산 가능 곡선 예제는 구간별 기회비용이 10 → 20 → 30 → 40 으로 커져 체증을 보여 준다.
- c01 레슨은 그래프 대신 표를 쓴다 (생산 가능 곡선은 표로 제시). 그래프 렌더러가 수요·공급 곡선 전용이므로, 생산 가능 곡선
  그림이 필요하면 렌더러를 넓히는 작업이 따로 필요하다.
- SDG 사례는 세 레슨 모두 SDG 12 (책임 있는 소비와 생산). 선택지 3개마다 편익·비용·가정이 있고 정답 없는 토론 질문으로 끝난다.

- "반드시·전혀·모든·무조건·절대" 가 든 오답 선택지 0개 (자동 점검).

  다르다 → 같은 기능을 연습하는 문항으로 유지. 사람이 확인해 주기 바란다.
- 최종 평가는 레슨 퀴즈와 다른 상황을 쓴다. 합격 기준과 재응시 횟수는 최종 평가 문항 승인 **뒤에** 따로 승인한다.
