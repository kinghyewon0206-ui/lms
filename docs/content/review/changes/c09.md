## Checked and correct (research-method teaching)
- Difference-in-differences: formula, the 3-point worked example, parallel-trends assumption (now with the pre-trend caveat).
- Correlation vs. causation, lurking variables, selection-bias decomposition E[Y₁ − Y₀ | P] + (E[Y₀ | P] − E[Y₀ | N]), random assignment.
- Cost-effectiveness (C ÷ ΔY, one outcome) vs. benefit–cost analysis (B ÷ C or B − C, all in money) are defined consistently at every level.
- Present value PV = amount ÷ (1 + r)ᵗ matches c07 A = P(1 + r)ᵗ; real value = nominal ÷ (price index ÷ 100) matches c04 at every level of c09; elasticity ε = %ΔQ ÷ %ΔP; unemployment rate = unemployed ÷ labor force.
