## 1. 방법
1. **강좌별 편집 (AI 편집자 10명):** c01~c09 와 진단평가를 하나씩 맡아 모든 레벨·개념·예제·그래프·SDG 사례·출처·문항을 읽고, 확정 결함을 직접 수정했다.
   공통 용어 결정(한계 원칙, 외부효과, 탄력성, 실질 가치, 실업률, 논쟁적 정책 서술, 개인 금융 범위)을 모든 강좌에 같은 기준으로 적용했다.
2. **독립 검증 (별도 AI 검토자 9명):** 편집 기록을 보지 않고 모든 문항을 먼저 직접 풀고, 모든 숫자를 다시 계산하고, 가정·결론·난이도·학습목표 측정 여부를 따졌다.
   결과: 검토자들이 풀어 본 문항은 모두 정답 키와 일치했고, 숫자 재계산 오류는 0. 검토자가 찾은 확정 결함·판단 항목은 원래 편집자가 2차로 반영했다.
   2차 수정 뒤 바뀐 문항과 c06·c07 전체(첫 검토 보고의 문항 수가 실제보다 적었음)는 별도 검토자가 다시 풀었다 (5장 끝 참고).
3. **총괄 QA:** 강좌 간 용어 일관성 검색, 문항 품질 도구(절대 표현 오답, 정답만 긴 선택지, 중복 지문, 예제 복사), 공개 문서 정답 노출 검사, 상태·이력 점검.
   AI 검토자끼리의 의견 일치는 사실의 증거로 쓰지 않았다. 출처를 열어 확인한 것만 출처로 인용했다.
