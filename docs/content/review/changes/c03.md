## Unresolved / uncertain
- **12번 출처:** 세금 vs 배출권 선택 기준(불확실성과 한계피해 기울기)은 표준 환경경제학 결과지만 출처 레지스트리에 이를 직접 확인한 항목이 없다. 이번 세션에서 페이지를 열어 확인하지 않았으므로 출처를 추가하지 않고 "a standard model result" + "economists disagree" 로 표현을 좁혔다. 교사가 출처(예: 환경경제학 교재)를 확인해 연결하기를 권한다.
- **7번 클럽재:** OpenStax 13.3 기존 확인 기록에는 클럽재 언급이 없다. 표준 2×2 분류로 썼으며 출처 확인은 사람 몫.
- **대기 분류(8번):** "흡수 용량 = 공유자원, 안정된 기후 = 공공재" 는 교육적 정리다. 교재마다 다르게 부르며 레슨이 이를 밝힌다.
- L2 학습목표 1은 여전히 세 범주(사유재·공공재·공유자원)만 명시한다. 학습목표는 유지 규칙에 따라 바꾸지 않았다 (클럽재는 본문 보충).
