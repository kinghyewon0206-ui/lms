L3 의 social cost = private cost + external cost, Pigouvian tax·command-and-control·tradable permits 는 c03 용어 그대로.

## 6. 앞으로의 시각화 아이디어 (이번에 구현하지 않음 — 코드 변경 없음)
> 현재 그래프 렌더러는 직선 수요·공급과 수평 가격선만 그린다. 아래는 사람이 따로 승인할 경우를 위한 메모이며, 레슨 본문은 이 시각화가 있다고 말하지 않는다.

1. **두 나라 PPF 차트:** Northland (600 자전거 ↔ 300톤)·Southland (100 ↔ 200톤) 직선 PPF, 무역 전 점 (480, 60)·(50, 100), 무역 후 소비점 (530, 70)·(70, 130), 교역조건 p = 1 의 교역선. 입력으로 p 를 0.5~2 사이에서 움직이면 두 나라 이득이 어떻게 나뉘는지 보여 줄 수 있다. 필요: 축이 "재화 A·재화 B" 인 새 그래프 유형(기존 P–Q 그래프와 별도), 서버와 JS 가 같은 계산 함수 사용.
2. **관세 그래프 음영:** 기존 관세 그래프에 CS 손실·PS 이득·관세 수입·DWL 두 삼각형을 색 영역으로 표시하고, 가격선과 D·S 의 교점(80·70·30·20)을 점으로 표시. 필요: `price_lines` 교점 표시와 영역(polygon) 렌더링.
3. **환율 환산기 (위젯):** 호가 방향 토글(BEL per ARI ↔ ARI per BEL), 가격 입력 → 양방향 환산, 절상률·절하율 동시 표시(비대칭 강조). 가상 통화만 사용, 실제 환율 기본값 금지. 반올림 규칙 명시.
4. **공급망 단계 막대 (stacked bar):** 단계별 부가가치(8·12·30)를 누적 막대로, 외부 비용(가정)을 별도 색으로 덧붙여 "사적 비용 vs 사회적 비용" 을 보여 줌.
5. **회복력 기대비용 슬라이더:** 교란 확률을 0~30% 로 움직이면 버퍼 있음/없음 기대비용 두 직선이 교차하는 지점(손익분기 확률)을 표시. L3 상급 예제 값($20,000 vs $16,000, 5% 에서 역전)을 재현해야 한다.
- 모든 위젯은 영어 전용 라벨, "Hypothetical example" 문구, 시뮬레이션 라벨 규칙(`econova/simulations.py`·JS·템플릿 동일)을 따라야 한다. 강좌 JSON 에 `simulations` 는 넣지 않았다.
