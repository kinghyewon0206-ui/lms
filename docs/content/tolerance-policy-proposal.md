# 수치형 문항 허용 오차 정책 제안 (검토용, 아직 적용하지 않음)

> 내부 문서 (2026-11-14). 정답 값은 넣지 않았다. 문항별 정답·허용 범위 전체 표는 비공개 `~/econova-private/review/tolerance-review-2026-11-14.md`.
> **이 문서는 제안이다. 사람 승인 전까지 채점 정책·정답 키를 바꾸지 않는다.**

## 1. 현황
- c01~c09 와 새 진단평가(v4)의 수치형 문항 71개. 51개는 아래 정책과 이미 같고, 18개는 정책을 적용하면 더 엄격해지며, 2개(c02-final-q7, c06-l2-q2)는 반올림 안내가 없어 지문 수정이 먼저 필요하다. 새 진단평가의 수치형 2문항은 이미 정책(R2)과 같다.
- 대부분의 '더 엄격해짐'은 정답이 정확한 정수인데 허용 오차가 0.01 인 경우다. 학생은 정수를 입력하므로 **채점 결과가 실제로 바뀌는 경우는 거의 없다** (39.99 같은 입력만 달라짐).

## 4. 적용 방법 (승인 뒤)
1. 승인된 규칙에 따라 비공개 원본(`~/econova-private/i18n/*.full.json`)의 tolerance 와 지문(반올림 안내)을 고친다.
2. 분리 도구로 공개 파일·정답 키를 다시 만든다. 지문이 바뀐 문항만 문항 version 이 오른다. 허용 오차만 바뀐 경우는 공개 파일이 그대로라 version 이 오르지 않는다 (정답 키만 바뀜).
3. 학생 응시 기록이 없는 초안 단계라 지금 적용하는 비용이 가장 낮다.

## 5. 결정이 필요한 것
- R4: 근사를 허용하는 문항(c04-l3-q3)과 허용하지 않는 문항(c07 실질수익률)을 지문 표현으로 구분할지, 한쪽으로 통일할지.
- R5: 복리 금액 문항에 1단위 여유를 둘지(권장) 아니면 엄격하게 ½단위로 할지.
