## 4. 채점 영향 요약
- **실제로 판정이 바뀔 수 있는 문항은 6개**: c02-final-q8, c04-final-q5, c04-l2-q4, c06-l1-q3, c07-final-q4, c07-l2-q2 (반올림이 틀렸거나 중간 반올림한 답이 더 이상 정답이 아님). 이 중 5개는 '마지막 단계에서만 반올림' 안내를 함께 넣어 정답자가 불리해지지 않게 한다.
- R1 로 0.01 → 0 이 되는 정수 답 문항은 정수를 입력하는 한 판정이 같다.
- 아직 학생 응시 기록이 없는 초안이라, 적용 비용은 지금이 가장 낮다.

## 5. 적용 절차 (승인 뒤에만)
1. 비공개 원본에서 지문(안내 문장)과 tolerance 를 고친다.
2. 분리 도구로 공개 파일·정답 키를 다시 만든다: 지문이 바뀐 문항만 문항 version 이 오르고 공개 지문(fingerprint)이 바뀐다. 허용 오차만 바뀐 문항은 정답 키만 바뀐다.
3. 수치형 정답 재계산과 QA, 전체 테스트를 다시 돌린다.
