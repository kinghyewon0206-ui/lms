# 대회 시연 계획 (2026-11-21 개정)

> 내부 문서. **아무것도 공개하거나 승인하지 않았다.** 모든 강좌·레슨·평가는 draft, 공개 0. AI 검토는 사람 승인이 아니다.
> 초안 학습자료를 외부에서 볼 수 있게 만드는 모든 단계는 소유자의 명시적 승인 뒤에만 한다.

## 1. 심사위원 경험 (목표)
URL 접속 → 랜딩(프로젝트 이해) → Continue with Google → 대시보드 → 진단평가 → 추천 강좌 → 레슨(초급·중급·상급) → 퀴즈 → 진도·리포트 → 시뮬레이션 → AI 튜터 → SDG 캡스톤.
- 심사위원은 Vercel 계정이 필요 없다 (운영 도메인은 Standard Protection 에서 공개, `docs/deployment-vercel.md` 6장).
- 학습 기능은 ECONOVA 로그인(Google 또는 이메일)으로 보호, 관리 화면은 관리자만.
- 심사위원 계정은 Google 로그인 시 자동으로 학생 계정이 된다 (관리자 아님). 실제 학생 기록은 쓰지 않는다.

## 2. 지금 막혀 있는 것 (코드가 일부러 막는 것)
| 기능 | 운영에서 열리는 조건 | 지금 |
|---|---|---|
| 강좌·레슨 | 강좌 `published` + 레슨 자료 승인 | 0개 |
| 퀴즈·최종 평가 | 평가 승인 + 정답 키 | 0개 |
| 진단평가 | 진단 승인 + 정답 키 | 닫힘 |
| AI 튜터 | 승인·공개된 레슨에서만 + `ECONOVA_AI_PROVIDER=openai` | 닫힘 |
| 시뮬레이션 (`/lab`) | 로그인 | 열림 (수요·공급, 탄소세) |
| 캡스톤 (c09) | c09 공개 + 루브릭 승인 | 닫힘 |

**그래서 지금 그대로 배포하면 심사위원은 랜딩·로그인·대시보드·시뮬레이션만 볼 수 있다.**

## 3. 권장 시연 범위 (가장 작은 완전한 학습 여정)
- **c01 Economics & Choices** (3레슨 + 퀴즈 3 + 최종 평가): 기초 → 완주까지 보여 줌
- **c03 Market Failure** (탄소세 시뮬레이터가 레슨 안에 들어 있음): 시뮬레이션 + SDG 7·13
- **c09 SDG Economic Challenge** (캡스톤)
- **진단평가** (12문항, 추천 기준은 "잠정"으로 표시됨)
- 시뮬레이션 2개, AI 튜터 (위 강좌 레슨에서)
- 나머지 c02·c04~c08 은 "Coming soon" 카드로 보인다.

## 4. 공개 방법 선택지 — 소유자 결정 필요
| | A. 사람 검토 후 정상 공개 (권장) | B. 대회 미리보기 모드 (새 기능, 미구현) |
|---|---|---|
| 방법 | 소유자가 c01·c03·c09·진단평가를 `/admin/content` 에서 검토·승인 → 서명된 릴리스 계획 → `content-release-apply` → 공개 커밋 | 환경변수로 지정한 초안 강좌만 로그인 사용자에게 보여 주는 별도 경로 |
| 장점 | 기존 안전장치 그대로. 리허설 테스트(`tests/test_release_rehearsal.py`)가 이미 c01·c09 공개 경로를 검증. 표시도 정직함(사람이 승인함) | 사람 검토 없이 시연 가능 |
| 단점 | 소유자 검토 시간 (강좌당 1~2시간, `docs/content/review/c01-checklist.md`) | 승인 우회 경로가 생김. 모든 화면에 "AI-reviewed draft, not approved by a person" 표시 필요. 구현·테스트 반나절 이상. **초안을 외부에 공개하는 것이므로 소유자 승인 필수** |
| 정답 키 | 공개한 평가 키만 Secret Manager 에 | 지정 강좌 키만 |
| 권장 | **예** — 이 범위는 4개 단위라 하루 안에 검토 가능 | A 가 일정상 불가능할 때만 |

B 를 고를 경우 설계 원칙: 공개 상태(`published`)를 바꾸지 않는 별도 플래그 / 지정 강좌만 / 로그인 필수 / 관리 기능 없음 / 정답·해설은 기존처럼 서버 채점 후에만 / 모든 화면에 초안 표시 / 대회 후 즉시 끄기.

## 5. AI 튜터 설정 (확인 결과, 실제 호출은 하지 않음)
- 공급자: `ECONOVA_AI_PROVIDER` = off(기본) / mock(로컬 전용, 운영에서 켜면 시작 거부) / openai.
- 모델: `ECONOVA_AI_MODEL`, 기본 `gpt-4o-mini` (2026-11-13 academy 키로 실제 연동 시험 통과: 6회 요청).
- 한도(기본값, 환경변수로 조정): 학생 1인 하루 20회, 전체 하루 300회, 입력 600자, 대화 기록 6개, 출력 700토큰, 타임아웃 20초, 같은 질문 20초 내 중복 차단, 대화 30일 보존.
- 실패 시: 시간 초과·오류면 학생에게 안내 문구를 보여 주고 점수·진도에는 영향 없음. 튜터는 점수를 바꾸지 않고, 레슨 자료 범위로 답하며 근거가 부족하면 그렇게 표시한다.
- 비용 상한: 전체 하루 300회 × 출력 최대 700토큰 → gpt-4o-mini 기준 하루 비용이 작다(정확한 금액은 OpenAI 요금표·academy 결제 한도로 소유자가 확인). OpenAI 대시보드에서 프로젝트 사용 한도도 설정 권장.
- 필요한 소유자 행동: (1) 대회 기간 동안 academy 키 사용 승인 (2) `OPENAI_API_KEY` 를 Vercel Sensitive 변수로 직접 입력 (3) 시연 전 1회 실제 질문으로 확인 승인.

## 6. 5분 시연 흐름
| 시간 | 화면 | 말할 내용 |
|---|---|---|
| 0:00 | 랜딩 | 고등학생용 영어 경제 플랫폼. 9개 강좌가 SDG 와 연결. 첫 화면의 시장 그래프를 직접 움직여 보임 |
| 0:40 | Continue with Google → 대시보드 | 비밀번호 없이 시작. 새 계정은 학생 권한 |
| 1:00 | 진단평가 → 결과 | 6개 영역 프로필 → 추천 강좌·난이도 (잠정 기준이라고 표시) |
| 1:40 | c01 레슨 | 같은 개념을 3단계 수준으로. 예제·SDG 사례·출처 |
| 2:20 | 퀴즈 → 결과 → 대시보드 | 서버 채점(정답은 브라우저로 가지 않음), 진도 갱신 |
| 3:00 | c03 탄소세 시뮬레이터 / `/lab` | 세금을 올리면 생산량·가격·외부 비용이 어떻게 변하는지 |
| 3:40 | AI 튜터 | 레슨에 대한 질문 → 레슨 근거로 답. 하루 한도 |
| 4:15 | c09 캡스톤 → 리포트 | 9단계 정책 제안서, 루브릭 자기평가 |
| 4:45 | 마무리 | 품질 근거: 독립 재풀이, 숫자 재계산, 사람 승인 절차(승인 ≠ 공개) |

준비물: 시연용 Google 계정, 미리 데운 서버, 네트워크 장애 대비 녹화 영상(보호된 배포에서 녹화).

## 7. 공개 순서 (A 기준)
1. 소유자: c01·c03·c09·진단평가 검토·승인 (+ 출처 확인, 합격 기준·루브릭 승인)
2. 릴리스 적용·공개 커밋 → 테스트 → feature 브랜치 푸시
3. Vercel 미리보기(보호됨)에서 전체 흐름 확인
4. 소유자 공개 승인 → `competition` 브랜치 → 운영 배포 → Standard Protection → 시크릿 창에서 확인
5. 대회 후: 심사위원 계정·AI 대화 정리 여부, 공개 유지 여부 결정
